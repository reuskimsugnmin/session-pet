# 세션 펫 (Session Pet)

AI 코딩 에이전트 세션을 여러 개 병렬로 돌릴 때, 어느 세션으로 돌아오든
"이 세션의 목표, 지금 상태, 다음에 시킬 일"을 바로 떠올리게 해주는 macOS 플로팅 마스코트.

**이 저장소는 배포본 전용입니다** — 설치 파일(DMG), 설치 안내, 서드파티 고지, 랜딩페이지가 여기 올라옵니다.
개발 저장소는 비공개입니다.

## 설치

[최신 릴리스](https://github.com/reuskimsugnmin/session-pet/releases/latest)에서 DMG를 받으세요.
Apple Silicon(arm64) 전용입니다.

설치와 권한 안내는 [install.md](install.md)를 보세요 (첫 릴리스와 함께 올라옵니다).
