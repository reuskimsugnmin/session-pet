## 아이콘 (Lucide ISC · Feather MIT · lobehub 로고 MIT)

# 아이콘 라이선스 고지

이 디렉터리(`app/assets/icons/ui/`)의 SVG 18개는 [Lucide](https://lucide.dev)에서 가져왔다. 각 파일 첫 줄의
`<!-- @license ... -->` 주석이 저작권·허가 고지 역할을 한다. 나머지 2개(`logo-claude`·`logo-openai`, 2026-09-18
추가)는 Lucide 가 아니라 `@lobehub/icons-static-svg`에서 왔다 — 아래 "lobehub 로고 2종" 절을 본다.

**정정(2026-09-18, 최종 브랜치 리뷰 실측)**: "vite 가 빌드 산출물에서 이 주석을 지운다"는 최초 서술은 이
저장소의 구현 경로에는 틀렸다 — `install-icon-sprite.ts` 가 `?raw` import 로 SVG 원문을 **문자열 그대로**
번들에 박으므로, `npm run build` 산출물(`out/renderer/assets/*.js`)에 18개 라이선스 주석이 리터럴로 남는다
(`grep -c '@license' out/renderer/assets/index-*.js` → 19, 18개 아이콘 + 정규식 리터럴 1). `docs/2026-09-15-motion-token-shape.md`
§5 의 "지운다" 관측은 다른 자산 파이프라인(디자인 리뷰용 정적 배포)에서 나온 것으로 보이며, `?raw` 경로에는
적용되지 않는다. **런타임에는** `buildIconSprite()`(`theme/icon-sprite.ts`)가 정규식으로 주석을 제거하고 DOM
에 주입하므로 화면에 보이는 스프라이트에는 안 남는다 — "지워지는 자리"는 번들 문자열이 아니라 **DOM 스프라이트**다.
이 파일은 어느 쪽이든(번들 문자열에 남든 DOM 에서 지워지든) 정확한 고지 전문이 한 곳에 있어야 한다는 목적으로
유효하다.

## 두 라이선스로 나뉜다 (실측 2026-09-18)

Lucide 저장소는 `check`·`chevron-down`·`minimize-2`·`moon`·`plus`·`x` 를 포함한 약 110개 아이콘을
[Feather](https://github.com/feathericons/feather) 프로젝트에서 가져온 것으로 표시하고, 이 아이콘들은
**MIT** 라이선스(저작권자 Cole Bemis)를 따로 적용한다. 나머지는 **ISC**(저작권자 Lucide Icons and Contributors).
우리 18종 중 6종이 MIT 목록에 있다:

| MIT (Feather 유래)                             | ISC (Lucide)                                                                                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| check, chevron-down, minimize-2, moon, plus, x | arrow-right-to-line, circle-alert, clipboard-copy, clipboard-list, copy, grip-vertical, maximize-2, pause, refresh-cw, sparkles, user, zap |

(대조 방법: `curl -s https://raw.githubusercontent.com/lucide-icons/lucide/main/LICENSE` 의 Feather 유래 아이콘
이름 목록과 `manifest.json` 의 18개 이름을 대조. 이전까지 `manifest.json`·`README.md` 는 "출처: Lucide, ISC
라이선스"로만 적어 이 구분을 놓치고 있었다.)
