세션 펫
다운로드

“내가 이 세션에서
뭐 하고 있었더라…
다음에 뭘 시키려고 했더라…”

세션을 여러 개 띄워 두고 오가다 보면 돌아올 때마다 이 질문을 해요. 스크롤을 올려 처음부터 다시 읽거나, 아까운 토큰을 써서 “지금까지 뭐 했고 다음에 뭐 할지 정리해 줘” 를 또 시키죠.

세션 펫은 세션마다 목표, 진행 중인 작업, 다음 할 일, 완료된 일을 들고 있다가 옮겨 가는 순간 보여줘요. 다시 읽지 않아도, 정리시키지 않아도 돼요.

멀티 세션에서의 컨텍스트 스위칭 문제를 이렇게 해결해요

세션을 옮겨 다닐 때마다 초기화되는 기억

이렇게 해결해요

세션의 목표, 진행 중인 작업, 다음 남은 작업, 완료된 작업을 턴이 끝날 때 정리해 두고, 보고 있는 세션을 항상 따라와 보여줘요. 세션을 파악하려고 히스토리를 다시 읽거나, 토큰을 써서 정리를 요청할 필요가 없어요.

“끝나면 다음엔 이거 해야지” 하다가 뭐 시키려고 했더라…

이렇게 해결해요

다음에 할 작업을 AI 가 자동으로 to-do 로 정리해 주고, 떠오른 작업도 한 줄로 바로 추가할 수 있어요. 진행 중인 작업이 끝나면 그중 당장 시키고 싶은 걸 골라 버튼 하나로 프롬프트에 입력해요. Enter 는 직접 누르니까 엉뚱한 세션에 들어갈 일이 없어요.

다른 작업하다 방치되는 내 에이전트

이렇게 해결해요

펫이 에이전트의 작업 상태를 표정과 말풍선으로 화면에 항상 보여줘요. 작업 중인지, 끝났는지, 내 답을 기다리는지 탭을 돌아보지 않아도 알 수 있어서 다른 일을 하다가 에이전트를 방치하는 일이 없어요.
